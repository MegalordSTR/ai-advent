## 🔗 Ключевые связи и зависимости

### Технологические зависимости
```
SadConsole → Графика → Интерфейс → Геймплей
C# → Архитектура → Системы → Геймплейные механики
Lua → Модификации → Контент → Реиграбельность
```

### Геймплейные циклы
```
Генерация уровня → Исследование → Встреча с врагом → Бой → Добыча → Прогрессия
Характеристики → Боевые модификаторы → Шансы успеха → Тактические решения
Уровень персонажа → Сложность врагов → Баланс → Ощущение прогрессии
```

### Потоки развития
```
MVP → Тестирование → Балансировка → V1 → Расширение → Сообщество
Техническая база → Геймплейные системы → Контент → Полировка → Релиз
```

## 💡 Идеи для дальнейшего развития

### Приоритет 1 (после V1)
1. **Система навыков (skills)** — добавление проверок навыков (Stealth, Perception, etc.)
2. **Расширенная магия** — больше заклинаний, школ магии
3. **Сложные ловушки** — механические, магические, экологические

### Приоритет 2
1. **Настройка генерации** — параметры для игрока (размер, сложность, тематика)
2. **Дополнительные расы** — эльфы, дварфы, полурослики (если добавить расы)
3. **Система репутации** — отношение фракций (дружественные/враждебные NPC)

### Приоритет 3
1. **Сюжетные элементы** — квесты, NPC с диалогами
2. **Продвинутая экономика** — торговля, крафтинг
3. **Мультиплеер** — кооператив (очень долгосрочно)
