# Контекст проекта: Dungeon Crawler: Console Descent

## 🎮 Общая информация
- **Название:** Dungeon Crawler: Console Descent
- **Тип:** Пошаговая консольная roguelike RPG
- **Платформа:** Windows (первичная), кросс-платформенность через .NET
- **Статус:** Начальная фаза разработки
- **Технологии:** C# (.NET 6+), SadConsole, Lua (для модификаций)

## 🎯 Ключевые характеристики
- **Видение:** "Классическая глубина D&D в современной оболочке"
- **Целевая аудитория:** Мужчины 25-35 лет, фанаты D&D и roguelike
- **Бизнес-модель:** Бесплатно + пожертвования

## 🛠️ Технические детали

### Геймплейные системы
- **Движение:** Пошаговое по сетке 60x30
- **Бой:** Упрощённые правила D&D 3.5 (броски d20, AC, спасброски)
- **Персонаж:** 6 характеристик, 3 класса (Воин, Маг, Паладин в V1)
- **Генерация:** Клеточные автоматы для процедурных уровней
- **Инвентарь:** Слотовая система, магические предметы (+1, +2)

### Архитектура
- **GameManager:** Управление состояниями игры
- **MapGenerator:** Генерация уровней клеточными автоматами
- **CombatEngine:** Логика боя (броски кубиков, проверки)
- **Entity System:** Наследование от GameObject для всех сущностей
- **Save/Load:** JSON сериализация

### Интерфейс
- **Визуальный стиль:** ASCII псевдографика с цветовым кодированием
- **Панели:** Карта (60x30), статус, инвентарь
- **Управление:** WASD/стрелки + мышь для выбора целей

## 📈 Roadmap

### MVP (Minimum Viable Product)
- 1 класс (Воин), 1 уровень, базовый бой, инвентарь
- Генерация клеточными автоматами, система сохранения

### V1 (Первая полноценная версия)
- 3 класса (Воин, Маг, Паладин), 5 уровней, финальный босс
- Расширенная система предметов, множественные сохранения

### Долгосрочное развитие
- Lua-модификации, тематические уровни
- Кастомизация генерации, дополнительные классы и враги
