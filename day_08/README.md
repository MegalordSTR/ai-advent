# AI Agent Platform

Модульная платформа для работы с DeepSeek API через различные интерфейсы (веб, CLI, мобильные приложения). Поддерживает загрузку кастомных агентов с промптами из markdown‑файлов.

## Архитектура

Платформа разделена на независимые модули:

- **Core** – чистая бизнес‑логика (загрузка агентов, общение с DeepSeek API, управление историей)
- **HTTP Server** – REST API сервер, предоставляющий доступ к Core через HTTP
- **Web UI** – современный веб‑интерфейс (отдельный деплоймент), работающий через HTTP API
- **CLI (опционально)** – терминальный интерфейс, может работать как через HTTP API, так и напрямую с Core

Все модули независимы и могут быть развернуты отдельно. Любой UI (веб, десктоп, мобильный) может быть подключен через HTTP API.

## Возможности

- **Модульная архитектура**: Core, HTTP API, UI разделены, независимое развертывание
- **HTTP API**: RESTful API для интеграции с любыми клиентами (веб, мобильные, десктоп приложения)
- **Веб‑интерфейс**: современный SPA на HTML/CSS/JS, работает через HTTP API
- **Кастомные агенты**: загрузка промптов из `.md` файлов
- **Поддержка DeepSeek**: API‑клиент с таймаутами и обработкой ошибок
- **Персистентность истории**: сохранение диалогов в SQLite базе данных между сессиями
- **Безопасность**: загрузка API‑ключа из `.env.local` или переменной окружения, CORS настройки

## Установка и запуск

### Запуск HTTP сервера с веб‑интерфейсом

1. **Убедитесь, что установлен Go 1.21+**
   ```bash
   go version
   ```

2. **Клонируйте репозиторий**
   ```bash
   git clone <репозиторий>
   cd ai-agent-cli
   ```

 3. **Установите зависимости**
    ```bash
    make deps
    # или
    go mod download
    ```

 4. **Соберите и запустите HTTP сервер**
    ```bash
    make run
    ```
    Эта команда соберёт приложение в `bin/server` и запустит сервер на порту 8080 (можно изменить переменной окружения `PORT`).
    
    **Альтернативно, вручную:**
    ```bash
    make build
    ./bin/server
    ```

5. **Откройте веб‑интерфейс**  
   Перейдите по адресу [http://localhost:8080](http://localhost:8080) в браузере.

### Запуск только HTTP API (без веб‑интерфейса)

Если вы хотите использовать только API, удалите директорию `web-ui/public` или отключите обслуживание статики в коде сервера.

## Конфигурация

### API‑ключ DeepSeek

Получите ключ на [platform.deepseek.com](https://platform.deepseek.com) и сохраните его:

**Вариант A: Файл `.env.local`** (не коммитится)
```bash
echo 'DEEPSEEK_API_KEY=sk-ваш_ключ' > .env.local
```

**Вариант B: Переменная окружения**
```bash
export DEEPSEEK_API_KEY=sk-ваш_ключ
```

### Агенты

Агенты определяются в markdown‑файлах внутри директории `agents/`.  
Формат файла:
```markdown
# Имя агента
Описание (опционально, может быть многострочным).

## Prompt
Системный промпт для модели.
```

**Пример: `agents/helper.md`**
```markdown
# Помощник
Общий помощник для решения любых вопросов.
## Prompt
Ты полезный ассистент. Отвечай кратко и по делу.
```

При запуске приложение сканирует `agents/` и показывает список доступных агентов.

## Хранение данных

Приложение автоматически сохраняет историю диалогов в SQLite базе данных `chat_history.db`:

- **Автоматическое сохранение**: каждое отправленное сообщение и ответ ассистента сохраняются сразу после отправки/получения
- **Автоматическая загрузка**: при повторном запуске диалога с тем же агентом вся предыдущая история загружается
- **Очистка старых сообщений**: поддерживаются только последние 200 сообщений на агента (настраивается в коде)
- **Расположение базы данных**: файл `chat_history.db` создается в текущей рабочей директории при первом запуске

Для очистки истории удалите файл `chat_history.db` или используйте SQLite-клиент для управления данными.

## Использование

После запуска сервера (`make run`) платформа доступна через:

### Веб-интерфейс
Откройте в браузере: [http://localhost:8080](http://localhost:8080)

Веб-интерфейс предоставляет:
- Выбор агента из доступных
- Чат с выбранным агентом
- Просмотр истории сообщений
- Отправка сообщений в реальном времени

### REST API
Платформа предоставляет RESTful API для интеграции:

**Базовый URL:** `http://localhost:8080/api`

**Эндпоинты:**
- `GET /agents` — список всех доступных агентов
- `GET /agents/{agent}/messages` — история сообщений для указанного агента
- `POST /agents/{agent}/messages` — отправить сообщение агенту

**Примеры использования API:**
```bash
# Получить список агентов
curl http://localhost:8080/api/agents

# Получить историю сообщений агента "Помощник"
curl http://localhost:8080/api/agents/Помощник/messages

# Отправить сообщение агенту "Помощник"
curl -X POST http://localhost:8080/api/agents/Помощник/messages \
  -H "Content-Type: application/json" \
  -d '{"message": "Привет!"}'
```

## Тестирование

Проект включает комплексную тестовую стратегию. Для запуска тестов используйте Makefile:

### Основные команды тестирования

```bash
# Запустить все тесты
make test

# Запустить тесты с детектором гонок (race detector)
make test-race

# Запустить линтер (golangci-lint)
make lint
```

### Ручной запуск (без Makefile)

```bash
# Все тесты
go test -v ./...

# С детектором гонок
go test -race -v ./...

# Только unit-тесты
go test -v ./core/... ./internal/...

# Только интеграционные тесты
go test -v ./integration/...
```

### Типы тестов

- **Unit-тесты**: Тестирование отдельных модулей и функций
- **Интеграционные тесты**: Тестирование API эндпоинтов и взаимодействия компонентов
- **Тесты с race detector**: Выявление проблем с параллелизмом

### Покрытие кода

Для проверки покрытия кода:
```bash
go test -cover ./...
```

## Разработка

### Локальная разработка

Для удобства разработки используйте Makefile:

```bash
# Загрузить зависимости
make deps

# Собрать и запустить все тесты
make test

# Запустить тесты с детектором гонок
make test-race

# Запустить линтер (требуется установленный golangci-lint)
make lint

# Собрать приложение
make build

# Собрать и запустить сервер
make run

# Полный CI-пайплайн
make ci
```

### Добавление нового агента

1. Создайте файл `agents/<имя>.md` с промптом (см. формат ниже)
2. Перезапустите приложение — агент появится в списке доступных агентов

**Формат файла агента:**
```markdown
# Имя агента
Описание агента (опционально, может быть многострочным).

## Prompt
Системный промпт для модели.
```

### Расширение функциональности

- **Новые API эндпоинты**: добавьте обработчики в `server/handlers/`
- **Бизнес-логика**: модифицируйте `core/service/service.go`
- **Интеграция с DeepSeek API**: настройки в `internal/deepseek/client.go`
- **Хранение данных**: работа с `internal/storage/sqlite.go`
- **Middleware**: добавьте новые middleware в `server/middleware/`

### Тестирование

Проект использует комплексное тестирование:
- **Unit-тесты**: для отдельных функций и методов
- **Интеграционные тесты**: для API эндпоинтов в `integration/`
- **Тесты с детектором гонок**: для выявления проблем с параллелизмом

Запуск всех тестов: `make test` или `make test-race`

## Безопасность

- API‑ключ никогда не логируется
- `.env.local` добавлен в `.gitignore`
- Таймауты на сетевые операции (60 секунд)
- Проверка ошибок закрытия ресурсов (response body, файлы)

## Ограничения

- История сообщений сохраняется в SQLite базе данных с ограничением на количество (по умолчанию 200 последних сообщений на агента)
- Поддерживается только модель `deepseek-reasoner`
- База данных `chat_history.db` создается в текущей директории при первом запуске
