# AI Agent CLI

Интерактивный CLI‑клиент для работы с DeepSeek API через терминальный интерфейс (TUI). Поддерживает загрузку кастомных агентов с промптами из markdown‑файлов.

## Возможности

- **TUI‑интерфейс**: выбор агента, диалог в реальном времени
- **Кастомные агенты**: загрузка промптов из `.md` файлов
- **Поддержка DeepSeek**: API‑клиент с таймаутами и обработкой ошибок
- **Конкурентность**: неблокирующий ввод‑вывод через BubbleTea
- **Безопасность**: загрузка API‑ключа из `.env.local` или переменной окружения

## Установка

1. **Убедитесь, что установлен Go 1.21+**
   ```bash
   go version
   ```

2. **Клонируйте репозиторий**
   ```bash
   git clone <репозиторий>
   cd ai-agent-cli
   ```

3. **Установите зависимости**
   ```bash
   go mod download
   ```

4. **Соберите бинарник**
   ```bash
   go build -o ai-agent-cli
   ```

## Конфигурация

### API‑ключ DeepSeek

Получите ключ на [platform.deepseek.com](https://platform.deepseek.com) и сохраните его:

**Вариант A: Файл `.env.local`** (не коммитится)
```bash
echo 'DEEPSEEK_API_KEY=sk-ваш_ключ' > .env.local
```

**Вариант B: Переменная окружения**
```bash
export DEEPSEEK_API_KEY=sk-ваш_ключ
```

### Агенты

Агенты определяются в markdown‑файлах внутри директории `agents/`.  
Формат файла:
```markdown
# Имя агента
Описание (опционально, может быть многострочным).

## Prompt
Системный промпт для модели.
```

**Пример: `agents/helper.md`**
```markdown
# Помощник
Общий помощник для решения любых вопросов.
## Prompt
Ты полезный ассистент. Отвечай кратко и по делу.
```

При запуске приложение сканирует `agents/` и показывает список доступных агентов.

## Использование

Запустите собранный бинарник:
```bash
./ai-agent-cli
```

**Управление в TUI:**
- `↑/↓` — выбор агента
- `Enter` — выбрать агента и начать диалог
- `Ctrl+Enter` — новая строка в поле ввода
- `Enter` (в диалоге) — отправить сообщение
- `Ctrl+C` / `q` — выход
- `/exit` — выход из диалога

## Разработка

### Добавление нового агента

1. Создайте файл `agents/<имя>.md` с промптом
2. Перезапустите приложение — агент появится в списке

### Расширение функциональности

- **Новые команды в TUI**: добавьте обработку в `tui.go:Update`
- **Дополнительные параметры API**: модифицируйте `deepseek.go:chatRequest`
- **Поддержка других моделей**: измените `Model` в запросе

### CI/CD

Проект готов к подключению GitHub Actions. Пример конфигурации `.github/workflows/ci.yml`:

```yaml
name: CI
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version: '1.26'
      - run: go mod download
      - run: go test -race -cover ./...
      - run: golangci-lint run
```

## Безопасность

- API‑ключ никогда не логируется
- `.env.local` добавлен в `.gitignore`
- Таймауты на сетевые операции (60 секунд)
- Проверка ошибок закрытия ресурсов (response body, файлы)

## Ограничения

- История сообщений хранится в памяти (без лимита)
- Нет персистентности диалогов
- Поддерживается только модель `deepseek-reasoner`
